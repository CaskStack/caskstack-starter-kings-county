# Kings County Distillery — CaskStack Starter Kit

> **New York City's Premier Craft Whiskey Distillery • Est. 2010**

A bespoke, standalone Statamic / Blade starter kit designed for craft whiskey distilleries, bourbon houses, and heritage distilleries, based on the historic aesthetic of **Kings County Distillery** ([kingscountydistillery.com](https://www.kingscountydistillery.com)) in the Brooklyn Navy Yard Paymaster Building.

---

## 🥃 Design & Brand System

- **Typography**:
  - Headings: `Cormorant Garamond` (Historic New York Distiller Serif)
  - Body: `Jost` / `Inter` (Crisp modern sans)
  - Technical / Bottle Labels: `Courier Prime` & `Space Grotesk` (Iconic typewriter label typography)
- **Palette**:
  - `kings-navy`: `#001A70` (Historic Paymaster Navy)
  - `kings-copper`: `#EE7A41` (Pot Still Flame & Charred Oak)
  - `kings-parchment`: `#FBF9F5` (Vintage Distiller Label Paper)
  - `kings-dark`: `#0E131F` (Charred Barrel Cask)

---

## 📦 Installation & Usage

Install via the Statamic CLI or CaskStack Theme Hub:

```bash
php please starter-kit:install CaskStack/caskstack-starter-kings-county
```

Or clone directly:

```bash
git clone git@github.com:CaskStack/caskstack-starter-kings-county.git
```
